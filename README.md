# Banco-de-dados-estudos

Repositório com os exercícios práticos em Fundamentos de Banco de Dados, usando SQLite no Node.js.

## Conteúdo

| Pasta | Tópico |
|---|---|
| [01-tabela-registro-campo](01-tabela-registro-campo/) | Banco de dados, tabela, registro e campo |
| [02-chaves-relacionamentos](02-chaves-relacionamentos/) | Chave primária (PK), chave estrangeira (FK) e relacionamento 1:N |
| [03-sql-crud](03-sql-crud/) | SQL com WHERE e as 4 operações do CRUD |
| [04-tipos-relacionamento](04-tipos-relacionamento/) | Relacionamento 1:1 (UNIQUE) e N:N (tabela de associação com JOIN) |

## Ferramentas usadas

Node.js, SQLite, Git e GitHub.
